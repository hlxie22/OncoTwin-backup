# OncoTwin App Checkpoint 2

Checkpoint 2 integrates the frozen Dynamic Scan V2-07 research release behind a localhost-only research-runtime boundary.

## Scientific boundary

- Deploy family: `r1_temporal_fixed`
- Frozen update: `selected_logits = PRE + 0.52 * (POST - PRE)`
- Patient-facing PFS: `1 - CIF(progression) - CIF(death)`; switch remains a competing event.
- Treatment-line identity is never supplied as a model-facing predictor. The repaired CKPT7R1 encoder also zeroes line identity internally.
- PRE and POST are generated by the repaired R1 event-preparation/cache path. POST differs by current scan evidence.
- The product does not fabricate a genomic tensor from positive-only report facts. Until an exact tested-gene/variant tensor is available, the frozen genomics-unavailable path is used.
- A dated metastatic-disease anchor and a dated, recognized current scan assessment are required. Otherwise the forecast is unavailable rather than guessed.
- The release remains a research model with independent external confirmation pending.

## Runtime

The web/API stay in `oncotwin-app`. Frozen PyTorch inference runs with the research interpreter via `scripts/app/run_model_service.sh`.
